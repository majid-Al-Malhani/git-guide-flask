# دليل Git — موقع Flask متعدّد الصفحات

موقع تعريفي بنظام Git، مبنيٌّ على Python باستخدام إطار **Flask**.
كل رابطٍ في القائمة يقودك إلى **صفحةٍ حقيقية مستقلّة** لها مسارها ومحتواها الخاص.

## هيكل المشروع

```
git-site-flask/
├── app.py               # تطبيق Flask ومسارات الصفحات
├── requirements.txt     # المكتبات المطلوبة
├── .gitignore           # ملفات يتجاهلها Git عند الرفع
├── templates/           # قوالب الصفحات (Jinja2)
│   ├── base.html        # القالب الأساسي (القائمة + التذييل)
│   ├── index.html       # الرئيسية
│   ├── what.html        # التعريف
│   ├── why.html         # الأهمية
│   ├── concepts.html    # المفاهيم + Git مقابل GitHub
│   ├── usecases.html    # الاستخدامات + سير العمل
│   ├── mistakes.html    # الأخطاء الشائعة وحلولها
│   ├── faq.html         # الأسئلة الشائعة + الدعوة للبدء
│   └── 404.html         # صفحة الخطأ المخصّصة
└── static/
    └── css/
        └── style.css    # التنسيقات المشتركة
```


## المسارات المتاحة

| المسار        | الصفحة              |
|---------------|---------------------|
| `/`           | الرئيسية            |
| `/what`       | التعريف             |
| `/why`        | الأهمية             |
| `/concepts`   | المفاهيم            |
| `/usecases`   | الاستخدامات         |
| `/mistakes`   | الأخطاء الشائعة      |
| `/faq`        | الأسئلة الشائعة      |

> أي مسارٍ غير موجود يعرض صفحة الخطأ 404 المخصّصة تلقائيًّا.

أسئلةٌ شائعة

إجاباتٌ موجزة عن أكثر ما يتساءل عنه المبتدئون في Git.

هل أحتاج Git إذا كنت أعمل بمفردي؟+

نعم. حتى في المشاريع الفردية يمنحك Git سجلًّا موثوقًا لعملك، وحرّيةً في التجربة، ونسخةً احتياطيةً منظّمة يمكنك الرجوع إليها في أي وقت.

هل Git صعبٌ على المبتدئين؟+

أساسياته بسيطة، ويكفي إتقان بضعة أوامر (add وcommit وpush) للبدء بفاعلية. أما المفاهيم المتقدّمة فتُتعلَّم تدريجيًّا مع الممارسة.

ما الفرق بين Git وGitHub؟+

Git أداةٌ تعمل على جهازك لتتبُّع التغييرات، بينما GitHub منصّةٌ سحابية تستضيف مستودعاتك وتتيح مشاركتها والتعاون عليها. يمكن استعمال Git دون GitHub، لكن دمجهما معًا هو الأكثر شيوعًا.

هل يصلح Git لغير ملفات الكود؟+

يعمل Git بأفضل صورةٍ مع الملفات النصّية (كود، توثيق، ملفات إعداد)، ويمكن استعماله لأي مشروعٍ قائم على النصوص. أما الملفات الثنائية الكبيرة فتُدار عبر إضافاتٍ مثل Git LFS.
